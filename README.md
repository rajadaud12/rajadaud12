### ⚡ About Me

I am a **Software Engineer** specializing in **Artificial Intelligence** and **Modern Web/Mobile Systems**. I architect and build end-to-end intelligent applications — from fine-tuning open-source LLMs and designing RAG pipelines to engineering high-concurrency FastAPI microservices and interactive Next.js web platforms.

- 🤖 **AI & Machine Learning**: Fine-tuning open-source LLMs (Llama, Mistral), RAG architectures, custom agentic workflows, PyTorch, Hugging Face.
- ⚡ **High-Performance Backend**: Building asynchronous microservices and scalable REST APIs using **Python (FastAPI)** and **Node.js / TypeScript**.
- 🌐 **Modern Full-Stack**: Crafting responsive SSR web applications with **Next.js**, **React**, and **Tailwind CSS**.
- 📱 **Mobile & Web3**: Engineering cross-platform apps with **Flutter** and gasless decentralized workflows (ERC-4337 Account Abstraction).
